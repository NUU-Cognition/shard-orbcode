# OrbCode (Deprecated)

Deprecated. OrbCode is now the ITE: load `flint shard start ite` (headless: `flint shard hstart ite`). A software product is a program of the template `software` of the ITE shard (`NUU-Cognition/shard-ite`), with its views in `Steel/Programs/<Name>/Views/`. The ITE gives the proof of each node from Orbtest, the review of a node against its code, and the check after a product task (`sk-ite-check_after_task`).

**Shorthand:** `orbc` | **Depends:** `@nuucognition/flint`

This source is a shell: it has no skill, workflow, template, knowledge, migration, or type. NUU Flint Task 1241 (2026-10-08) folded OrbCode into the ITE. A Flint that installs the published 1.1.1 keeps it. To move to the ITE, uninstall this shard (`flint shard uninstall orbc`) and install the ITE shard (`flint shard install @nuucognition/ite`).
